# AGENTS.md

Guide for AI agents and developers working on the GlowBots Plant Scanner.

## What this is

A web port of the Avonwood GlowBots' Python/Flet desktop app "Plant Scanner & Native Status Checker", extended with a Disposal tab and a field-optimized camera and identification pipeline. It is built with TanStack Start (React 19) + Tailwind 4 + shadcn/ui and deployed on Netlify. No database: the only persisted state is the demo email and intro completion in `localStorage`.

## Layout

```
src/
  components/
    app-shell.tsx     # Email gate → intro story → nav ribbon. Also Logo, PageBanner, SectionCard.
    field-camera.tsx  # Full-screen getUserMedia camera (zoom/torch/exposure/tap-focus, live meter, burst-sharpest capture)
    ui/               # shadcn components
  lib/
    identify.functions.ts  # Server fn: Pl@ntNet candidates + AI botanist (Anthropic via AI Gateway), cross-checked
    inat.ts                # Browser-side iNaturalist: place search, native status, map data
    image.ts               # Canvas helpers: quality scoring (brightness + Laplacian variance), woodland correction, resize
    plants.ts              # Confirmed-invasive list + DISPOSAL_GUIDES + GENERAL_METHODS (single source of species data)
  routes/
    __root.tsx  # HTML shell; mounts AppShell once so the gate persists across tabs
    index.tsx   # Home
    scan.tsx    # Location → photos → identify → result/native status/invasive alert
    disposal.tsx# ?species=<slug> selects a guide (validated against DISPOSAL_GUIDES)
    maps.tsx    # SVG Mercator map of status by state/province with pan/zoom
    about.tsx
public/img/woodland.png  # Hero image; always referenced through /.netlify/images
```

## Non-obvious decisions

- **Gate in root:** `AppShell` reads `localStorage` in `useEffect` (SSR-safe) and renders a loading emblem until then.
- **Identification accuracy:** the client sends up to 5 JPEGs (≤1600px), each tagged with an organ. Pl@ntNet gets them all with `organs` (habit → auto). The model (`claude-sonnet-5-5`) sees the photos, the region, and Pl@ntNet's top 6 candidates, and must return JSON (parsed with zod; confidence values >1 are normalized). When the two engines agree on a binomial, confidence is combined as `1-(1-a)(1-b)`. Disagreement caps it at 0.75. Either engine alone still works.
- **Woodland correction** is applied only when mean luma < 110 and the toggle is on. Quality is measured before correction for uploads and after correction for camera shots.
- **Invasive status** = iNaturalist `introduced` + listed in `plants.ts` → "confirmed invasive" (same rule as the original app). Adding a species to `DISPOSAL_GUIDES` also adds it to the invasive list.
- **Maps** use `listed_taxa` from the taxon record first, then per-place lookups (6 concurrent) for the rest, capped at the top 100 observed places.
- **Logo:** `Logo` loads `/glowbots-logo.png` and falls back to an emblem if it is missing.

## Conventions

- Use the `@/` import alias; PascalCase components; kebab-case route files; remove unused imports (strict TS).
- Theme colors live in `src/styles.css` (`--primary` forest green, plus `forest`, `leaf`, `moss`, `warn`, `danger` utility colors). Headings use `font-display` (Georgia).
- Server functions use `.validator(zod)`; never expose provider error bodies.
- `src/routeTree.gen.ts` is generated by the build. Don't edit it.
